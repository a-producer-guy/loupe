# Loupe

An assistant editor for scripted scenes. Drop the footage; Loupe watches every take, lines it up with the script and hands you a first cut you can direct.

- `app/`: the website and app (Next.js) at editloupe.com
- `worker/`: the proxy worker (Node + FFmpeg)
- [SETUP.md](SETUP.md): setting it all up
- [CLAUDE.md](CLAUDE.md): how it's built and the rules
