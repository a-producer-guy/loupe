# Sign-in emails

Supabase sends these (Backdrop project → Authentication → Emails → Templates). They're kept here so the wording and design live with the code; editing them here changes nothing until they're pasted into Supabase.

- `supabase-magic-link.html` → **Magic link or OTP**, subject `Your way into Loupe`
- `supabase-confirm-sign-up.html` → **Confirm sign up** (someone's very first sign-in), subject `Welcome to Loupe`

Loupe's picture is `public/email/loupe.png`, served from https://editloupe.com/email/loupe.png.
